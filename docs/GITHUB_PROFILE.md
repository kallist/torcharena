## Social preview: manual step required

The available GitHub connector/CLI tools expose no repository social-preview upload
operation. No upload is claimed. The final [PNG](assets/social-preview.png) is
1280 × 640, opaque, below 1 MB; [SVG](assets/social-preview.svg) is editable.

Repository → Settings → General → Social preview → Edit → Upload an image →
choose `docs/assets/social-preview.png`.

After upload, reopen the setting and check the selected image; inspect an external
share preview after caches refresh. Committing an image or changing README alone
does not configure this setting.

[GitHub's social-preview instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
